# Patterns — copy-paste skeletons

This directory holds canonical skeletons. The agent copies, renames, and fills `{{...}}` placeholders. Each skeleton is the ZDSWF-approved starting point.

Files:
- `managed-bo.template.md` — full managed RAP BO with draft (root + child + projection + service)
- `analytical-query.template.md` — analytical CDS with `@Analytics` for ALP
- `action-only-service.template.md` — service that exposes only actions (no CRUD)
- `value-help-view.template.md` — value-help CDS with associations

The skeletons here are abbreviated for size; for full content see the reference files (`rap-skeleton.md`, `cds-recipes.md`, etc.) and merge.
