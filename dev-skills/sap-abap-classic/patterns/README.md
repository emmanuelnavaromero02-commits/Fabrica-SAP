# Patterns — classic skeletons

Copy-paste skeletons for the canonical ZDSWF classic deliverables.

- `module-pool.template.md` — module pool + controller class + lock object
- `alv-report.template.md` — executable report + SALV ALV + controller class
- `bapi-wrapper.template.md` — class wrapping a BAPI for testability

Each pattern is a starting point. The agent renames, fills `{{...}}` placeholders, and adapts.
